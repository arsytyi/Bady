# Bady

Мобільний застосунок для нагадувань про прийом ліків і БАДів: гнучкий розклад, облік прийомів, запас таблеток і попередження про несумісні добавки.

Перша платформа: Android. Згодом, можливо, iPhone.

- Специфікація: [docs/SPEC.md](docs/SPEC.md)
- Дизайн-система: [design-system/MASTER.md](design-system/MASTER.md)

## Як встановити тестову збірку

1. Відкрийте вкладку **Actions** у репозиторії і виберіть останній успішний запуск **CI** на потрібній гілці.
2. Внизу сторінки завантажте артефакт **bady-apk** (zip з файлом `app-release.apk`).
3. Перекиньте APK на телефон і відкрийте його. Android попросить дозволити встановлення з цього джерела.
4. Під час першого запуску дозвольте сповіщення. У налаштуваннях застосунку можна дозволити точні нагадування.

Поки що збірка підписана тестовим ключем. Підписаний реліз з'явиться на кроці 4.

## Розробка

Потрібен Flutter 3.50 (stable).

```sh
flutter pub get
dart run build_runner build   # після змін у lib/data/database.dart
flutter gen-l10n              # після змін у lib/l10n/*.arb
flutter analyze
flutter test
flutter run
```

Структура:

- `lib/domain/` — логіка розкладу без залежностей від Flutter (`schedule_rule.dart`), групування нагадувань, форматування.
- `lib/data/` — база даних SQLite (drift).
- `lib/services/` — локальні сповіщення.
- `lib/ui/` — екрани і тема (`theme.dart`).
- `lib/l10n/` — переклади: українська (`app_uk.arb`) та англійська (`app_en.arb`).
